# Eigo-Wordbook
自分用英単語調をためしにつくってみる。

## ライセンス（使用データ）

| データセット | 著作者 | ライセンス |

| [CEFR-J Wordlist v1.5](https://github.com/openlanguageprofiles/olp-en-cefrj) | Tono Lab, TUFS | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |

| [EJDict](https://github.com/kujirahand/EJDict) | kujirahand | Public Domain |
